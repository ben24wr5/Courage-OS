# Courage OS

A talking green-screen computer that boots from a USB stick. Claude is the brain, and it answers out loud with text and a picture.

**Get the ISO:** open the **Releases** page on the right and download `courage-os.iso`.
GitHub builds a fresh one automatically whenever the code changes. You can also go to **Actions** → **Build Courage OS ISO** → **Run workflow**.

Then see [GUIDE.md](GUIDE.md) for how to put it on a USB, start it, and add your Claude API key.
